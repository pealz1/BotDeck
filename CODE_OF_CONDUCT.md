# Code of Conduct

BotDeck follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and assume good intent. Disagree with ideas, not people.
- No harassment, insults, discrimination, sexualized content or personal attacks.
- Do not publish anyone's private information, including bot tokens, user IDs or private messages.
- Help newcomers; everyone was new once.

These rules apply in issues, pull requests, discussions and anywhere else you represent the project.

## Reporting

If someone breaks these rules, report the comment or account with GitHub's **Report content** option and mention [@pealz1](https://github.com/pealz1) in a new, brief issue if it needs maintainer attention. Do not repeat the offending content there. Maintainers may edit or remove content, and may block people who break these rules, as described in the Contributor Covenant's enforcement guidelines.
